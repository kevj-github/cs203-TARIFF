# 📘 DB_GUIDE.md

## 🔑 Role of Database Maintainer

As the database maintainer, your job is to:

- Keep the schema (tables) in **Supabase** up to date.  
- Add/seed new data (tariffs, products, taxes).  
- Make sure schema matches what the backend expects.  

---

## 1️⃣ Accessing the Database

1. Go to [Supabase Dashboard](https://app.supabase.com/).  
2. Select our project.  
3. Open the **Table Editor** (or SQL Editor).  
4. You’ll see existing tables:
   - `products`  
   - `tariff_rules`  
   - `indirect_tax_rules`  
   - `countries`  
   - `calculations` (optional)  
   - `calculation_audits` (optional)  

👉 These tables were created once by migrations but are now managed **directly in Supabase**.  
⚠️ Note: We disabled Flyway (`spring.flyway.enabled=false`) in the backend, so the backend won’t try to recreate them.  

---

## 2️⃣ Updating the Schema

If backend devs need a new table/column, add it in **Supabase SQL Editor**.

**Example: Add a `tariff_rules` table**
```sql
CREATE TABLE IF NOT EXISTS tariff_rules (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  origin_iso2 VARCHAR(2) NOT NULL,
  dest_iso2   VARCHAR(2) NOT NULL,
  hs_code     VARCHAR(10) NOT NULL,
  rule_type   VARCHAR(20) NOT NULL,   -- e.g. 'ad_valorem'
  rate_value  NUMERIC(12,6) NOT NULL, -- percent or amount
  rate_unit   TEXT NOT NULL,          -- 'PERCENT' or 'USD_PER_UNIT'
  valid_from  DATE NOT NULL,
  valid_to    DATE
);
